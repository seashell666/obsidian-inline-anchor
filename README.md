# 一行多锚点 (Inline Multi Anchor)

Obsidian 插件：在一行文字里放多个行内锚点，阅读视图完全隐藏标记，点击链接精确跳到**指定词语**，目标行瞬间到顶部并闪烁高亮。

## 解决什么问题

Obsidian 原生块锚点 `^id` 有两个硬伤：
1. 只能放在段落末尾，不能行内
2. 一个段落只能挂一个锚点——可一句话里经常同时出现好几处需要跳转的地方

本插件让你在一个段落里放任意多个锚点，每个锚点精确到某个**词**，互不干扰。

## 用法

### 1. 在正文里标记锚点

在想跳转的词语上用 `{id|词}` 包住它：

```
你已经中了我的独门{du_gu_001|毒蛊}，没有我的对应{jie_gu_001|解蛊}，七天之后，必定化为脓血而死。
```

- **id 规则**：蛊虫名每个字拼音全拼 + 下划线连接 + 三位编号
  - 毒蛊第 1 次 = `du_gu_001`
  - 留影存声蛊第 1 次 = `liu_ying_cun_sheng_gu_001`
- 阅读视图里 `{...}` 标记**完全隐形**，你看到的只是干净的"毒蛊""解蛊"
- 编辑视图里能看到标记，方便维护

### 2. 在档案/目录里链接到这个位置

```
[[0016-尽收囊中#du_gu_001|0016 尽收囊中 · 毒蛊第1次]]
[[0016-尽收囊中#jie_gu_001|0016 尽收囊中 · 解蛊第2次]]
```

### 点击链接后会发生什么

- 自动打开对应章节
- 目标行**瞬间滚动到窗口顶部**（和原生块锚点一样，无滑动动画）
- 目标词**黄色高亮约 4 秒**后渐隐
- 长文档很靠后的锚点也能准确定位（自动触发懒加载渲染）
- 鼠标悬停链接时，弹出预览窗口显示锚点所在的那一段，且**只高亮当前链接对应的词**

## 适用场景

- 小说解构：为每只蛊虫/人物/地点建档案，档案里列全部出场位置，点击直达那个词
- 学术笔记：一段里引用多处，精确跳到引用词
- 任何"一行多锚点、精确到词"的场景

## 技术原理

- **渲染**：`registerMarkdownPostProcessor` 在阅读视图渲染后，把 `{id|词}` 文本节点替换成 `<span id="id">词</span>`，标记彻底隐形
- **跳转**：拦截 `workspace.openLinkText`，识别我们的 id，用 Obsidian 原生 `applyScroll(line)` 按行瞬间定位（同时触发懒渲染解决长文档后段锚点），再用 MutationObserver 找到目标词加高亮动画
- **预览**：拦截 page-preview 的 `onLinkHover`，弹出锚点所在段落，只高亮当前链接对应的词

## 安装

1. 把 `main.js`、`manifest.json`、`styles.css` 放到 `.obsidian/plugins/inline-multi-anchor/`
2. 重启 Obsidian
3. 设置 → 第三方插件 → 启用"一行多锚点"

## 开发

```bash
npm install
npm run build
```

编译产物 `main.js` 复制到插件目录即可。
